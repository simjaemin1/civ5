# 규칙서 모호점 · 빠진 데이터

엔진 구현 중 규칙서만으로 확정하지 못한 부분. 구현은 아래 "현재 구현"대로 임시 처리했고, 확정되면 갱신한다.

## 모호한 규칙
| # | 내용 | 현재 구현 |
|---|---|---|
| 1 | 시작 행복: 2장은 "카드에 나온 값", 13장은 "시작할 때 모두 +1, 중국은 1을 더 받습니다"라고 적혀 있어 서로 안 맞음 | 카드에 적힌 값만 사용 |
| 2 | ~~연결선 없는 기술의 선행 조건~~ → **해결**: 12쪽 도표를 읽어 보니 2·3열 기술은 모두 선으로 이어져 있고, 선이 없는 기술(공공행정·교육학·강선·교체형부품·원자론·통합작전군)만 "같은 비용의 다른 기술" 규칙을 적용하면 됨 | 도표대로 구현 |
| 3 | 불모지 탈출: 버린 타일을 어떻게 하는지 불명 | 덱에 돌려 넣고 섞음. 첫 라운드에 한 번만 |
| 4 | 도시를 세운 그 차례에 이어서 일꾼 배치·연구까지 하는지 | 도시 건설 후 같은 차례를 계속 진행 |
| 5 | 도시가 2개일 때 문명 카드의 턴당 식량·망치 보너스, 문자의 식량→과학 변환이 어느 도시에 적용되는지 | 첫 도시에 적용, 변환은 도시 순서대로 차감 |
| 6 | 새로 얻은 타일(첫 5타일 이후)이 어느 도시 소속인지 | 첫 도시 소속 |
| 7 | 문명 능력의 "타일" 조건(러시아 툰드라 등)이 복합 지형 카드(예: 툰드라,언덕)에 적용되는 범위 | 카드에 해당 지형이 하나라도 있으면 적용 |

## 기술 트리
사용자가 아이콘 이름을 확인해 확정함 (경제학, 고고학, 과학이론, 천문학, 로봇공학, 핵융합). 앵무조개 아이콘은 생물학(작은 아이콘이 전함).

## 군사 카드
- 25종의 전투력·체력·방어력·공격 방향·특수 효과를 `militaryCards.json`에 입력함 (원자폭탄은 전투 능력치 없이 사용 효과만).
- 보병·원거리·창병·공성·전함 계열은 **왼쪽·가운데·오른쪽 방향 카드가 따로 있음** (사용자 확인): `variantDirs`. 전함도 같은 구조로 가정했다.
- 도표 테두리 색: 보라=정책(확인됨), 빨강=위대한 장군(기마술은 확인됨, 강선·군사과학·레이더는 추정), 노랑=문자·인쇄기술, 파랑=세계화·아폴로(의미 미확인).

## 빠진 데이터
- 타일 카드 160장 목록 (지금은 `placeholderDeck.ts`의 임시 덱)
- 정책 카드 8장 외 세부, 불가사의 카드의 진척도 원 개수
- 기술 효과: 규칙서 본문에 나온 것만 입력함 (그 외 기술은 군사 카드·자원 해금으로만 쓰임)
