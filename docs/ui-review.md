# UI/UX 평가와 수정 내역

작성: 2026-10 · 대상: `src/ui/` 핫시트 화면 (온라인 전환 전)
근거: 규칙서(`docs/rules.md`), 온라인 계획(`docs/online-plan.md`), UI 코드, 1440px·390px 화면 스크린샷. 실제 사용자 테스트가 아니라 **이론적 평가**다.

## 1. 게임의 성격과 사용자

- 자원을 짜내는 유로 게임과, 숨겨서 배치하는 전투를 합친 형태다. 식량·망치·과학·금을 모아둘 수 없어서 **매 차례가 "배치 → 산출 → 나누기" 퍼즐**이다.
- 상대와 부딪히는 곳은 세 군데다: 기술 독점(같은 라운드에 앞사람이 고른 기술), 불가사의 경매(우선도 순으로 투자하고 금액은 공개), 전쟁(숨겨서 배치하고 방향에 따라 공격).
- 한 판이 길다. 최대 180라운드이고, 차례 하나가 6단계다.
- 사용자는 두 부류다: **설계자(규칙 검증)** 와 **온라인 친구들(2~5인)**.

## 2. 원래 잘 맞던 점

1. 지금 단계의 패널만 보여 줘서 규칙서 3장의 진행 순서와 화면이 그대로 겹친다.
2. 엔진으로 결과를 미리 보여 준다: 일꾼 배치 화면의 예상 산출, 연구 화면에서 식량을 과학으로 바꾼 뒤 정산 결과.
3. 실물 카드 그림을 쓴다. 전투력 별의 위치가 곧 공격 방향이다.
4. 버튼마다 못 하는 이유("망치 부족 5/6")를 보여 주고, 규칙 위반은 오류 문구로 돌려준다.
5. 전투 결과를 장면으로 다시 보여 주고, 되돌리기와 가림막이 있다.

## 3. 약점과 수정 내역

| # | 약점 | 수정 |
|---|---|---|
| ① | **규칙상 공개된 정보를 화면이 안 보여 줌.** 이번 라운드 불가사의 투자액(`state.investments`)과 선전포고(`state.declarations`)를 UI 어디에서도 읽지 않았다. 규칙서 6장("뒷사람은 앞사람 투자액을 보고 정한다")과 10장("받은 쪽은 자기 차례에 대비한다")의 핵심 정보가 로그에만 있었다. | 오른쪽 곁패널에 **선전포고 목록**("나를 노림" 강조)과 **불가사의 경쟁**(이번 라운드 투자액, 1위, 공동 1위 경고)을 넣었다. 생산 화면 맨 위에 **선전포고 경고 띠**를 띄우고(공격 측과 내 군사 카드 장수 표시), 불가사의 줄마다 이번 라운드 투자액과 "이 금액이면 단독 1위 / 공동 1위라 아무도 못 얻음 / 🔨N 이상 필요"를 보여 준다. 보드의 목표 타일에는 ⚔ 표시를 붙였다. |
| ② | **전투 배치에 판단을 돕는 장치가 없음.** "내 2번의 왼쪽 = 상대 4번" 같은 뒤집힌 자리 계산을 사람이 머릿속으로 해야 했다. 상대의 공개 정보가 없었고, 대상 고르기는 `<select>` 목록이었다. 작은 카드에서는 방향 별이 잘 안 보였다. | 내 자리 위에 **상대 자리 줄(마주 보는 순서)과 공격 화살표**를 그리고, 칸마다 "⚔7 받음 (내 3번, 4번)"과 "↖ 왼쪽 ⚔4 → 상대 2번 / 빈 공간"을 보여 준다. **상대가 낼 수 있는 카드**의 종류·장수·체력·방어력을 보여 주되, 방향은 비공개라 뺐다. 대상 고르기는 칩 버튼으로 바꿨다. 그림 카드(160px 이하)에는 빨간 방향 화살표를 겹쳐 보여 준다. 좁은 화면에서도 4칸을 유지한다. |
| ③ | **같은 조작이 계속 반복되고, 남은 자원을 경고하지 않음.** | **"↻ 지난 차례와 같은 배치"** 버튼(사람마다 기억, 지금 올릴 수 없는 타일은 뺌)과 "모두 내리기"를 넣었다. **Enter = 이 단계 확정** 단축키를 넣었다. **"할 일 없으면 넘기기"** 설정을 켜면, 연구할 수 있는 기술이 없거나 망치·금으로 할 일이 없을 때 자동으로 넘기고 이유를 알려 준다. 남은 자원은 **두 번 확인**하게 했다: 생산할 수 있는 망치나 승급할 수 있는 금을 남기고 생산을 끝낼 때, 연구할 수 있는데 건너뛸 때, 놀고 있는 일꾼이 있는데 빈 타일도 있을 때, 손에 카드가 남았는데 전투 자리가 빌 때. |
| ④ | **세로 한 줄로 이어지는 긴 화면.** 1440px 화면에서도 오른쪽이 비고, 상대 현황과 로그는 스크롤해야 보였다. | **두 칸 배치**(1100px 이상)로 바꿨다. 왼쪽은 지금 할 일, 오른쪽은 스크롤해도 따라오는 곁패널(차례 순서와 문명별 요약, 선전포고, 불가사의 경쟁, 최근 기록)이다. 기존 문명 표는 곁패널과 겹쳐서 없앴다. |
| ⑤ | **온라인에서는 기다리는 시간이 가장 큰 UX 문제.** 내정을 한 명씩 하고 시간 제한도 없어서, 누가 무엇을 하는지 보여 주는 화면이 필요하다. | 곁패널에 **이번 라운드 차례 순서**(✓ 끝남, ▶ 지금, 남음)를 넣었다. AI·다른 사람 차례에는 **대기 화면**(지금 단계와 방금 한 일)을 보여 주고, **탭 제목으로 알린다**("▶ 한국 차례"). 기다리는 동안 다음 배치를 미리 짜 두는 기능은 서버의 뷰(`view`)가 생긴 뒤 온라인 M3 단계에서 만든다. |
| ⑥ | **패널마다 긴 안내문.** 다섯 판째부터는 화면만 차지한다. | 머리줄의 **"안내문" 체크**로 켜고 끈다. 끄면 패널 안내문이 사라지고 숫자만 남는다. 설정은 이 브라우저에만 저장된다(`civ5-ui-prefs`). |
| ⑦ | **모바일에서 불편함.** 첫 도시를 세울 때 면을 드롭다운으로 골랐다. | 도시 세우기를 **십자 모양 자리에 직접 놓기**로 바꿨다. 타일을 눌러 집고 다른 칸을 누르면 자리가 바뀐다. 전투 배치도 좁은 화면에서 마주 보는 순서가 유지된다. |

## 4. 수정 후 평가

| 사용자 | 이전 | 이후 |
|---|---|---|
| 설계자 (규칙 검증) | 높음 | 높음 (변화 없음, 안내문을 끄면 화면이 짧아짐) |
| 보드게임 경험자 (오프라인 핫시트) | 중간 | 높음: 공개 정보가 다 보이고 전투 계산 부담이 줄었다 |
| 온라인 친구 (2~5인) | 낮음~중간 | 중간: 화면은 준비됐고, 기다리는 동안 미리 짜기·알림음은 서버 연결 단계에서 만든다 |

## 5. 남은 일 (온라인 단계에서)

- 기다리는 동안 다음 차례 일꾼 배치를 미리 짜 두기. 서버가 보내 주는 뷰가 필요하다.
- 내 차례 알림음 또는 브라우저 알림 (탭 제목 표시는 지금 됨).
- 대기 화면에 "누가 접속이 끊겼는지" 표시 (계획 3.4: 접속이 끊기면 무제한 대기).
- 곁패널의 "나"는 지금은 마지막으로 입력한 사람이다. 온라인에서는 접속한 사람으로 바꾼다.

## 6. 코드 위치

- `src/ui/SidePanel.tsx` — 차례 순서·선전포고·불가사의 경쟁·최근 기록
- `src/ui/gameInfo.ts` — 선전포고 목표 이름, 이번 라운드 투자 순위
- `src/ui/autoSkip.ts` — 할 일 없는 단계 판정, 쓸 수 있는 과학의 최댓값
- `src/ui/battleView.ts` — 카드가 공격하는 상대 자리 (`targetSlot`은 엔진 `war.ts`에서 export, 엔진 동작은 그대로)
- `src/ui/ConfirmButton.tsx` — 남은 자원 경고 후 두 번째 클릭에 실행, `data-hotkey`로 Enter 연결
- `src/ui/prefs.tsx`, `src/ui/prefsStore.ts` — 안내문·자동 넘기기 설정

# 2차: 선전포고 화면 · 코너케이스 검토 · 사용자 요청 반영

## 7. 선전포고 화면 다시 만들기

이전에는 "선전포고 → 러시아 도시1 · 사막" 같은 글자 버튼 목록이었고, 누르면 확인 없이 바로 선전포고됐다.

| 문제 | 수정 |
|---|---|
| **버그**: 탈환 목표가 "러시아 도시1 · ?"로 나옴 (내 도시의 타일을 상대 도시에서 찾음) | 목표 타일은 종류에 맞는 주인(탈환은 내 도시)에서 찾는다. 시뮬레이션 테스트로 모든 목표를 찾을 수 있는지 확인 |
| 타일 가치를 판단할 수 없음 (그림·자원 없음, 같은 이름 구분 불가) | **상대 영토를 십자 보드로 보여 주고 타일을 눌러 고른다.** 문명별 탭과 "내 타일 탈환" 탭. 고를 수 있는 타일은 빨간 테두리, 나머지는 흐리게 |
| 이길지 판단할 정보가 없음 | 고르면 **전투 전망 카드**가 뜬다: 종류·비용, 전투 카드 수(해안 전용 카드 반영), 동점이면 수비 승, 상대가 이번 라운드에 아직 대비할 수 있는지, 해안 보너스(영국·등대), 지형 효과(스키 보병·모호크·화차·캐롤리언), 같은 상대에게 걸린 다른 선전포고. 카드가 0장이면 "반드시 집니다" 경고 |
| 도시 공격까지의 진행 상황이 안 보임 | 도시마다 "사면 점령 n/4"를 표시하고, 두 번째 도시 때문에 첫 도시를 공격할 수 없으면 알려 준다. 일반 선전포고 카드에 "이기면 n+1/4". 도시 공격인데 공성 카드가 없으면 경고 |
| 누르면 바로 확정 | 전망 카드의 "이 타일에 선전포고"를 눌러야 실행된다 |
| 일꾼을 다 올리면 선전포고 단계가 설명 없이 건너뛰어짐 | 일꾼 배치 화면에 "선전포고하려면 일꾼 1개를 남겨 두세요"를 띄운다. 1개를 남기면 "놀고 있는 일꾼" 경고를 띄우지 않는다 |
| 선전포고를 받은 것이 글로만 보임 | **목표가 된 타일 위에 "⚔ 러시아 선전포고" 띠**를 표시한다 (내 보드·상대 보드·선전포고 화면 모두) |

## 8. 코너케이스 검토와 수정

엔진 코드와 UI를 하나씩 대조하며 검토했다. 화면 판단이 엔진과 같은지는 `src/ui/__tests__/uiLogic.test.ts`가 AI 게임을 진행하며 모든 상태에서 확인한다.

| 영역 | 코너케이스 | 수정 |
|---|---|---|
| 생산 | 첫 5타일에 해안이 없는 도시에서도 전함·제고이센 생산 버튼이 켜짐 (엔진 `producible`에는 해안 조건이 없음) → 누르면 오류. 남은 망치 경고·자동 넘기기도 잘못 판단 | `produceBlock`이 해안 조건과 망치까지 보고, 엔진이 받는지와 같은지 테스트한다 |
| 생산 | 만들 수 없는 이유가 늘 "6장 한도 또는 고유 유닛"으로 나옴 | 이유를 정확히: 기술 / 상위 카드로 생산불가 / 자원 타일 없음 / 6장 한도 / 고유 유닛 3장 소진 / 해안 / 망치 부족. 만들 수 없는 카드는 접어 둔다 |
| 생산 | 불가사의 투자액에 소수·음수·빈칸을 넣을 수 있음 | 정수로 고치고, 최소·최대를 벗어나면 이유를 보여 준다. 뒤에 투자할 사람이 없으면 "단독 1위 확정" |
| 생산 | 인도 카드 파괴·원자폭탄·만리장성이 한 번 누르면 바로 실행 | 확인을 받는다. 만리장성은 내 영토에 상대 장군이 있을 때만 보여 준다 |
| 생산 | 선전포고 경고의 카드 수에 원자폭탄·해안 전용 카드가 들어감 | 그 전투에 낼 수 있는 카드만 센다 |
| 정찰 | 정찰한 타일을 맡아두거나 맡아둔 타일을 돌려보내는 버튼이 배치 단계에만 있음 (엔진은 연구·생산 단계에서도 허용) | 연구·생산 단계에도 정찰 상자를 보여 준다. 돌려보내면 일꾼이 돌아와 선전포고에 쓸 수 있다 |
| 정찰 | 올린 일꾼이 꽉 찼거나 덱이 비었는데 정찰 버튼이 켜짐 | 이유를 보여 주고 끈다 |
| 연구 | 앞사람이 이번 라운드에 고른 기술이 말없이 사라짐 | "이번 라운드에 앞사람이 이미 연구한 기술"을 보여 준다 |
| 연구 | 식량·망치를 바꿔야 연구할 수 있는 기술이 그냥 흐림 | 누르면 필요한 만큼 바꾸는 안을 보여 주고 실행한다. 필요 이상 바꿨으면 "필요한 만큼만"을 제안한다 |
| 정책 | 전통으로 버릴 일꾼을 고를 수 없음 (규칙: 플레이어가 고른다) | 도시가 둘이면 도시별로 몇 개 버릴지 고른다 |
| 정책 | 외교를 고르면서 파괴할 장군을 고르지 않으면 효과가 사라짐 | 상대 장군이 있으면 첫 번째를 기본으로 골라 둔다 |
| 되돌리기 | 다른 사람 차례로 되돌리면 가림막 없이 그 사람의 비공개 화면이 보임 | 차례를 넘는 되돌리기는 가림막을 다시 띄운다 (설정 메뉴의 검증용 버튼) |
| 되돌리기 | 되돌린 뒤 "방금 일어난 일"이 남음, 자동 넘기기가 곧바로 다시 넘김 | 알림을 지우고, 되돌린 뒤에는 다음 행동까지 자동 넘기기를 멈춘다 |
| 단축키 | Enter를 누르고 있으면 여러 단계가 연달아 확정됨, `<summary>` 위 Enter와 겹침 | 반복 입력·조합키·summary·링크를 무시한다 |
| 전투 결과 | 한 번에 전투가 여러 개 끝나면 마지막 것만 보임 | 오래된 것부터 하나씩 보여 준다. 보는 사람이 수비 측이면 자기 카드가 아래에 온다 |
| 전투 배치 | 사람 둘이 핫시트에서 차례로 놓을 때 화면 상태가 남을 수 있음 | 전투·단계·사람마다 화면을 새로 만든다 |
| 저장 | 지난 차례 배치 기억이 브라우저 전체에 남아 새 게임에 섞임 | 게임 저장 파일 안에 함께 저장한다 |
| 저장 | 저장 공간이 없으면 말없이 실패, 깨진 저장이면 이어하기에서 오류 | 실패하면 경고 띠를 띄우고, 깨진 저장은 이어하기를 숨긴다 |
| 도시 세우기 | 불모지 탈출 손패가 바뀌어도 화면이 옛 타일을 기억함 | 손패가 바뀌면 화면을 새로 만든다. 불모지 탈출은 확인을 받는다 |
| 카드 확대 | Esc로 닫히지 않음 | Esc로 닫는다 |
| 글 | "러시아이(가)", "식량 2을(를)" | 받침에 맞춰 조사를 붙인다 (`josa`) |
| 머리줄 | 모바일에서 설정이 세 줄을 차지함 | "⚙ 설정" 메뉴로 접었다 (안내문, 자동 넘기기, AI 속도(저장됨), 검증용 되돌리기) |

## 9. 사용자 요청 반영

1. **타일 산출 표시**: 그림 카드 위에 겹치던 이모티콘 산출(🍎2 등)을 없애고 카드에 그려진 아이콘만 보여 준다. 기술·문명 효과를 반영한 실제 산출은 타일에 마우스를 올리면 보이고, 일꾼 배치의 "예상 산출"에 합계가 나온다.
2. **차례 단계 막대와 차례 안 되돌리기**: 화면 위에 "①② 일꾼 배치·산출 › ③ 기술 연구 › ④ 생산 › ⑤ 선전포고 › ⑥ 식량 정산 → 차례 끝"을 보여 준다. 지난 단계(✓)를 누르면 그 단계를 시작할 때로 돌아가고, "한 단계 되돌리기"는 이번 차례의 마지막 행동을 되돌린다. 차례가 끝나는 행동(선전포고 확정, 차례 끝내기)은 되돌릴 수 없다고 표시한다. 상태 안의 시드가 같으니 되돌린 뒤 다시 생산해도 카드 방향은 같다 (다시 뽑기 악용 없음).
3. **문화 타일 붙이기**: 도시가 둘 이상이면 문화로 얻은 타일을 바로 붙이지 않고(엔진 `pendingTiles`), 타일을 보여 준 뒤 붙일 도시로 **끌어다 놓거나** 도시 버튼을 누른다. 첫 5타일에 빈 면이 남은 도시는 그 면에 붙는다고 미리 알려 준다. 붙이지 않고 차례를 끝내면 기본 도시에 붙고, AI는 예전과 같은 도시에 바로 붙인다. 정산 때 얻은 타일(시스티나 성당 등)은 그 문명의 다음 차례 처음에 붙인다.
4. **선전포고 표시**: 목표가 된 타일에 띠로 표시한다 (7절).
